# Безопасность данных (форма Data safety)

Ответы выведены из кода Android-приложения 0.5.10 и сервера. Всё, что отмечено ⚠, владелец
подтверждает перед отправкой формы: это заявление Google от его имени.

## Общие вопросы

| Вопрос | Ответ | Основание |
|--------|-------|-----------|
| Собирает ли приложение данные пользователей | Да | время смен, имя, данные для входа |
| Передаются ли данные третьим лицам («sharing») | Нет | Sentry получает отчёты об ошибках как обработчик (service provider), это не «передача» по определению Google ⚠ |
| Шифрование при передаче | Да | HTTPS ко всем запросам |
| Можно ли запросить удаление данных | Да | через администрацию работодателя или e-mail ⚠ `{{CONTACT_EMAIL}}` |
| Срок хранения координат и фото | ⚠ не задан | в коде и документах срока нет; решает владелец: `{{EVIDENCE_RETENTION}}`. Форма Play этого не спрашивает, но политика конфиденциальности должна назвать срок |

## Типы данных

Приложение запрашивает `INTERNET`, `NFC`, `ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`,
`RECEIVE_BOOT_COMPLETED` и, для функции «Schichtnachweise», `ACCESS_FINE_LOCATION`,
`ACCESS_COARSE_LOCATION`, `FOREGROUND_SERVICE` и `FOREGROUND_SERVICE_LOCATION`. Фоновой геолокации
(`ACCESS_BACKGROUND_LOCATION`) нет. Фото делает системная камера (`TakePicture`), разрешения
`CAMERA` у приложения нет. Контактов, микрофона, рекламного ID нет.

**Геопозиция и фото включает не пользователь, а компания** (настройки компании «Schichtnachweise»,
по умолчанию выключено). Пока компания их не включила, приложение ничего из этого не собирает.

Служебные заголовки телефона (число несинхронизированных смен, время последней связи) хранятся
на сервере у работника, цель «функциональность приложения»; отдельного типа данных в форме для
них нет, они попадают под «Действия в приложении».

## Что НЕ собирается

Контакты, сообщения (SMS не читаются, только отправляются сервером при включённом входе), видео,
аудио, файлы, календарь, здоровье, финансовая информация, история веб-поиска, рекламный ID.

**Геопозиция и фото в этот список больше не входят**: см. строки таблицы выше. Если компания
не включает «Schichtnachweise», они не собираются, но форма Data safety описывает возможности
приложения, поэтому отмечать их нужно как собираемые.
